# AI-Powered Personal Finance & Expense Management System

An intelligent personal finance management application designed to help users organize expenses and understand their financial activities through web technologies and machine learning.

## 🚀 Project Overview

This project combines a MERN-based web application with a Python machine learning service to build a personal finance management platform.

## 🛠️ Technology Stack

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Machine Learning:** Python
- **Development Tools:** VS Code, Git, GitHub

## 📂 Project Structure

```text
Ai-Personal-Finance/
│
├── frontend/       # React frontend
├── backend/        # Node.js backend
├── ml-service/     # Python ML service
├── package.json
├── package-lock.json
└── README.md
```

## ✨ Key Components

- Personal finance management interface
- Backend API development
- MongoDB database integration
- Python-based machine learning service
- Integration between frontend, backend and ML service

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/anji-ngu/Ai-Personal-Finance-System.git
```

### 2. Navigate to the project

```bash
cd Ai-Personal-Finance-System
```

### 3. Install dependencies

Install frontend and backend dependencies in their respective folders.

### 4. Configure environment variables

Create the required `.env` files using your local configuration. Never publish passwords or API keys.

### 5. Run the application

Start the frontend, backend and ML service using their respective development commands.

## 🎯 Project Goal

To explore the integration of full-stack web development, database management and machine learning in a practical personal finance application.
